## 문의

위 주소로 메일 주세요. 아래를 함께 적어 주시면 빨리 도울 수 있습니다.

- 사용하는 기기와 운영체제 버전 (예: MacBook Air, macOS 26.1)
- 한눈 버전 — 한눈 정보 창에서 확인할 수 있습니다
- 어떤 형식의 문서에서 생긴 일인지 (`.md`, `.json`, `.pdf` 등)
- 어떻게 하면 다시 생기는지

문제가 생긴 문서를 보내 주시면 원인을 찾기 쉽습니다. 다만 개인정보나 회사 자료가 담긴 문서는 보내지 마세요. 같은 증상이 나는 짧은 예시면 충분합니다.

## 자주 겪는 문제

### 문서 속 그림이 보이지 않아요

운영체제 보안 정책 때문에 문서가 있는 폴더의 그림을 읽으려면 한 번 허용해야 합니다. 문서 위쪽에 뜨는 안내 막대의 **폴더 허용**을 누르세요.

인터넷 주소로 걸린 그림(`https://…`)은 불러오지 않습니다. 문서를 연 사실이 밖으로 알려지지 않게 하려는 것입니다.

### 더블클릭하면 다른 앱이 열려요

맥은 처음에 `.md` 파일을 다른 앱으로 엽니다. 한눈의 **설정 › 일반 › 기본 앱**에서 마크다운 · 텍스트 · 데이터 문서 · PDF를 각각 눌러 두세요. 이미 기본 앱인 형식에는 "기본 앱으로 설정됨"이 보입니다.

### 글자가 깨져 보여요

오래된 한글 문서는 UTF-8이 아닌 인코딩(CP949 등)으로 저장된 경우가 있습니다. 편집 모드에서 아래쪽 상태 표시줄의 인코딩을 눌러 다른 인코딩으로 다시 읽어 보세요. 파일 내용은 바뀌지 않습니다.

### 다른 앱에서 고친 내용이 반영되지 않아요

한눈은 열린 파일이 바뀌면 다시 읽어 옵니다. 한눈에서 고치던 중이었다면 어느 쪽을 남길지 먼저 묻습니다. 설정 › 일반의 외부 변경 감지가 켜져 있는지 확인하세요.

### 문서 안의 링크를 눌러도 다른 문서가 열리지 않아요

iPhone과 iPad에서는 링크한 문서가 있는 폴더에 접근을 허용해야 할 수 있습니다. 한눈이 띄우는 안내에 따라 폴더를 허용하세요.

### 업데이트 알림이 오지 않아요 (홈페이지에서 받은 Mac 버전)

**설정 › 일반 › 자동으로 업데이트 확인**이 켜져 있는지 확인하세요. 메뉴 막대의 <strong>한눈 › 업데이트 확인…</strong>으로 바로 확인할 수도 있습니다. App Store 버전은 App Store에서 업데이트됩니다.

## 업데이트 예정 기능

| 기능 | 상태 |
|---|---|
| 인터넷 주소로 걸린 그림도 허용하면 불러오기 | 업데이트 예정 |
| 프리뷰 테마 추가 | 업데이트 예정 |
| YAML 트리 · 목록 보기 | 업데이트 예정 |
| 각주 | 업데이트 예정 |
| 사용자 CSS · 프리뷰 글꼴 직접 지정 | 검토 중 |
| HTML · Word로 내보내기 | 검토 중 |
| 탭을 끌어서 순서 바꾸기 | 검토 중 |

필요한 기능이 있으면 메일로 알려 주세요. 다음 업데이트를 정할 때 참고합니다.

## 구매와 환불

- 홈페이지에서 받는 Mac 버전은 무료이고, App Store 버전과 기능이 같습니다
- App Store 버전은 한 번 구매하면 Mac · iPad · iPhone에서 모두 쓸 수 있고, 가족 공유로 최대 6명까지 함께 쓸 수 있습니다
- App Store 구매와 환불은 Apple이 처리합니다. 환불은 [Apple 문제 신고 페이지](https://reportaproblem.apple.com)에서 요청하세요
