## 快速上手

- **打开文件**：在访达中双击（需先设为默认应用）、按 `⌘O`、把文件拖进窗口，或从时钟（⏱）菜单打开最近的文档
- **新建文稿**：按 `⌘N` 或点按标签栏上的 `+`，会立即打开一个不用选择保存位置的**临时文稿**。内容会自动备份，退出后再打开也还在。按 `⌘S` 保存后就变成普通文件。
- **设为默认应用**：在 设置 › 通用 › 默认应用 中，可以分别为 Markdown、纯文本、PDF 和数据文档设置。

## 界面说明（Mac）

| 位置 | 内容 |
|---|---|
| 标题栏 | 左侧显示文档状态，右侧是三组按钮——**跳转**（时钟：标签页和最近的文档 / 位置：在访达中显示）· **显示**（正文宽度 / 目录 / 切换显示模式）· **导出与应用**（共享 / 设置） |
| 标签栏 | 打开的文档（类型图标 + 名称）· `+` 新建文稿 · 标签页有 2 个以上时，右侧显示数量 |
| 状态栏 | 仅在编辑时显示——行:列 · 编码（点按可重新读取）· 换行格式 |

标签页太多时可以左右滚动（触控板横向轻扫或鼠标滚轮都行）。

## 显示模式 — `⌘/`

在**预览 → 分栏 → 编辑**之间循环切换。

- **预览**：全屏显示排版后的文档，Markdown 文件默认如此
- **分栏**：左边编辑器、右边预览。分隔线可以拖动，每个标签页分别记住位置。两边滚动会自动对齐
- **编辑**：全屏编辑器，`.txt` 默认如此
- 数据文档（`.json` `.xml` `.yaml`）没有分栏，只在**预览 ⇄ 编辑**之间切换——详见下方“数据文档显示”

## 缩放

到处都一样：**触控板双指捏合**，或 **⌘+滚动**。

- 预览：缩放画面（缩小后一屏能看到更多内容）
- 编辑器：字号（11～24pt）
- PDF：页面缩放
- 图片、图表的放大窗口里也一样
- 菜单方式：`⌘ +` / `⌘ −` / `⌘ 0`（预览和编辑器分别记住）

## 语法面板 — 按住 `⌥`（Mac）

编辑时按住 `⌥`（Option），右下角会打开语法面板。按键位置和键盘一致，按住期间按对应的键即可插入格式。**所有格式都可切换**——同一个键再按一次就会取消。

| 键 | 功能 | 键 | 功能 |
|---|---|---|---|
| 1～6、0 | 标题 1～6 · 正文 | A | 切换标题级别 |
| S | 粗体（`⌘B`） | D | 斜体（`⌘I`） |
| F | 删除线 | G | 行内代码 |
| H | 项目符号 | J | 编号列表 |
| K | 复选框 | L | 引用 |
| Z | 链接（`⌘K`） | X | 图像 |
| C | 代码块（`⌘⇧K`） | V | 表格 |
| B | 分隔线 | | |

## 预览功能

- **快速切换字体**：点按工具栏中的"格式"按钮，即可切换正文和标题字体（宋体或黑体）以及主题（自动、浅色、深色）。它与"设置 › 预览"中的值相同，因此会应用到所有文稿，下次打开时也会保留。
- **目录**：按 `⌘⇧T` 或点按目录图标——在左侧面板显示，宽度可拖动调整。点按条目即可跳转
- **正文宽度**：全宽 / 宽 / 中等 / 窄（左右箭头图标）
- **图片与图表放大**：点按后弹出放大窗口。拖动 = 移动，捏合或 ⌘+滚动 = 放大，连按两下 = 适合窗口 ⇄ 100%，`Esc` = 关闭
- **文档间链接**：点按 `[文档](./其他文档.md)` 会在新标签页中打开（`文档.md#章节` 会跳到对应标题）。网页链接用浏览器打开
- 支持 **Mermaid 图表、公式（KaTeX）和 Front Matter 卡片**

## 编辑功能

- 完整支持中文、日文、韩文输入法（IME）——输入过程中不会被格式打断
- Markdown 语法高亮、行号、当前行高亮
- 保存时**按字节原样保留**——编码、BOM 和换行格式都与原文件一致
- 如果文字显示为乱码，点按状态栏中的编码，换一种编码重新读取

## 文件管理

- **检测外部更改**：其他应用修改了已打开的文件时会自动重新读取。如果你正在编辑，会用横幅先询问
- **恢复上次会话**：退出后再打开，标签页、显示模式、滚动位置都和原来一样
- **允许访问图片文件夹**：文档中的图片显示不出来时，请点按顶部横幅中的“允许文件夹…”授权访问（macOS 安全规则）

## PDF

- PDF 文件用阅读器打开（会记住所在页面）
- **Markdown 导出为 PDF**：文件菜单 → 导出为 PDF…。在保存窗口中可以选择**格式**（连续（单页）/ A4 页面）、**缩放**，以及**宽表格与图表适应宽度**

## 设置（`⌘,`）

- **通用**：主题（自动 / 浅色 / 深色）· 语言（韩语 / 英语 / 日语 / 中文，重新启动后生效）· 检测外部更改 · 默认应用 · 自动检查更新（仅限从官网下载的 Mac 免费版）
  - 默认应用——Hannun 已经是默认应用的格式，按钮处会显示 **“已设为默认”**
- **预览**：正文宽度 · 正文字体（衬线 / 无衬线）· 标题字体 · 字号 · **数据文档显示**（源文本 / 树 / 列表）
- **编辑器**：等宽字体 · 字号

## 支持的文件

| 类型 | 扩展名 | 预览 | 编辑 |
|---|---|---|---|
| Markdown | `.md` `.markdown` `.mdown` `.mkd` | 排版显示 | ✅ |
| 纯文本 | `.txt` | —（用编辑器打开） | ✅ |
| JSON · XML | `.json` `.xml` | 按设置显示为源文本、树或列表 | ✅ 语法高亮 |
| YAML | `.yaml` `.yml` | 源文本 + 折叠 | ✅ 语法高亮 |
| PDF | `.pdf` | 专用阅读器 | — |

- 任何格式的打开方式都一样——`⌘O`、从访达拖入、位置按钮（Mac）、文件按钮（iPhone · iPad）、文档中的链接
- 在文档里写的 `[其他文档](./其他文档.md)` 这类链接，只要是上面的扩展名，也会在 Hannun 内以新标签页打开

### 数据文档显示（JSON · XML · YAML）

数据文档在预览中可以**折叠、展开**着看。显示方式在 **设置 › 预览 › 数据文档显示** 中选择。文档打开时切换，会当场重新绘制。

| 方式 | 样子 |
|---|---|
| **源文本**（默认） | 按文件原样显示，可按括号折叠，和 VS Code 等编辑器一样。折叠的行显示为 `{ … },` |
| **树** | 去掉引号和括号，只显示名称和值。折叠行旁的小数字是其中包含的项数。结构相同的条目连在一起时会整理成**表格**，每次显示 200 行，可点按“再显示 N 行”继续查看 |
| **列表** | 把键、类型、值分成三栏显示，和 Xcode 属性列表一样 |

- **YAML** 只以源文本显示，可**按缩进**折叠。树和列表视图将在后续更新中加入
- 大文件（超过 1,000 个节点）打开时**只展开到第 2 层**
- 缩放、查找、导出 PDF、主题、正文宽度都和 Markdown 一样可用
- **折叠起来的文字不会被查找到**——因为它们不在屏幕上。请先展开再查找
- 预览中不能修改值。要修改，请按 `⌘/` 切换到编辑模式，改完按 `⌘S` 保存

## iPad · iPhone

- **打开文件**：点按文件按钮，从“文件”App 中选择文档。文档会在原位置打开，改动保存到原文件
- **语法面板**：点按编辑界面右下角的按钮打开
- **查找与替换**：iPad 上从菜单栏使用
- **缩放**：用双指张开或捏合
