## Common issues

### Images in my document don't show up

Because of operating system security rules, Hannun needs your one-time permission to read images in a document's folder. Click **Allow Folder…** in the banner at the top of the document.

Images linked from the web (`https://…`) aren't loaded. That way, no one can tell that you opened the document.

### Double-clicking opens a different app

Out of the box, your Mac opens `.md` files in another app. In Hannun, go to **Settings › General › Default App** and click the button for Markdown, text, data documents, and PDF. Types where Hannun is already the default show "Default."

### Text looks garbled

Some older files are saved in an encoding other than UTF-8 (CP949, for example). In the editor, click the encoding in the status bar at the bottom and reopen the file with a different encoding. The file itself isn't changed.

### Changes made in another app don't show up

Hannun reloads an open file when it changes. If you were in the middle of editing, it asks which version to keep first. Make sure detecting outside changes is turned on in Settings › General.

### Links in a document don't open the other file

On iPhone and iPad, Hannun may need permission to access the folder the linked document is in. Follow the prompt in Hannun to allow the folder.

### I'm not getting update alerts (Mac version from our website)

Make sure **Settings › General › Automatically check for updates** is turned on. You can also check right away from the menu bar with <strong>Hannun › Check for Updates…</strong>. The App Store version is updated through the App Store.
