# App Store 스크린샷 — 장면 캡처 요청

> 한눈 세션에게. 합성(문구 · 곁주석 · 규격 크기)은 putchamoe.github.io 쪽에서 한다.
> 틀과 문구: `tools/appstore/slide.html`, `tools/appstore/slides.json` · 굽기: `node tools/appstore/render.mjs`

## 먼저 사실 확인

1. 아이폰에서 메일 · 메신저로 받은 `.md` 를 **공유 버튼 → 한눈** 으로 열 수 있는가? 되면 그 공유 시트 화면도 캡처(`iphone-share`). 안 되면 아이폰 1번 장면을 바꾼다.
2. **분할 보기** 가 아이패드에서 되는가? 아이폰에서는?

## 캡처 목록

- 4개 언어(ko · en · ja · zh) 모두, **라이트**, 기존 preview 캡처와 같은 기종 · 크기 · 샘플
- 저장: `assets/hannun/store/{ko,en,ja,zh}/<이름>.png`
- 다크 장면은 기존 `preview-dark` 를 쓴다 — 새로 찍지 않아도 됨

| 기기 | 이름 | 화면 |
|---|---|---|
| Mac | `mac-table` | 샘플 문서를 표 · 수식 · Mermaid 가 한 화면에 보이게 스크롤 |
| Mac | `mac-quicklook` | Finder 에서 샘플 `.md` 선택 후 스페이스바 퀵룩 패널 (데스크톱 포함) |
| Mac | `mac-json` | 관측 기록 JSON — 트리 보기 |
| Mac | `mac-yaml` | 짧은 YAML — 원문 + 접기 (없으면 JSON 내용을 YAML 로 옮겨 만든다) |
| Mac | `mac-palette` | 편집 모드에서 ⌥ 를 눌러 문법 팔레트가 열린 화면 |
| Mac | `mac-scratch` | ⌘N 임시 문서에 몇 줄 쓴 화면 (창 제목 "이름 없는 문서 쓰는 중") |
| iPad | `ipad-table` | 목차 열고 표 · 수식이 보이게 스크롤 |
| iPad | `ipad-json` | JSON 트리 |
| iPad | `ipad-split` | 분할 보기 (되면) |
| iPad | `ipad-font` | 가가 팝오버 연 화면 |
| iPhone | `iphone-share` | 공유 시트에서 한눈 고르기 (1번이 되면) |
| iPhone | `iphone-table` | 표 · 수식이 보이게 스크롤 |
| iPhone | `iphone-json` | JSON 트리 |
| iPhone | `iphone-font` | 가가 팝오버 연 화면 |
| iPhone | `iphone-edit` | 편집 모드 |
