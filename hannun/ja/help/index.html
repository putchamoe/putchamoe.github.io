Hannun 使い方ガイド

ファイルの開き方、ショートカット、データファイルの表示などをまとめました。困ったときはサポートをご覧ください。

はじめに

  • ファイルを開く: Finder でダブルクリック（デフォルトApp に設定している場合）、⌘O、ウインドウへのドラッグ、時計（⏱）メニューの最近の書類
  • 新規書類: ⌘N またはタブバーの + — 保存先を聞かずに下書きがすぐ開きます。内容は自動でバックアップされ、アプリを終了して開き直してもそのまま残ります。⌘S で保存すると通常のファイルになります。
  • デフォルトApp の設定: 設定 › 一般 › デフォルトApp で、Markdown・テキスト・PDF・データ文書をそれぞれ登録できます。

画面の構成（Mac）

場所 内容
タイトルバー 左に文書の状態 · 右に 3 つのボタングループ — 移動（時計: タブ・最近の書類 / 場所: Finder で表示）· 表示（本文の幅 / 目次 / 表示の切り替え）· 書き出し・アプリ（共有 / 設定）
タブバー 開いている文書（種類のアイコン + 名前）· + 新規書類 · タブが 2 つ以上あると右側にタブの数
ステータスバー 編集中のみ — 行:列 · 文字コード（クリックで読み直し）· 改行コード

タブが多いときは左右にスクロールできます（トラックパッドの横スワイプ、マウスホイールのどちらでも）。

表示モード — ⌘/

プレビュー → 分割表示 → 編集 の順に切り替わります。

  • プレビュー: 整形した文書を全体に表示。Markdown ファイルの標準
  • 分割表示: 左にエディタ、右にプレビュー。境界線はドラッグで調整でき、タブごとに記憶されます。左右のスクロールは自動で連動します
  • 編集: エディタを全体に表示。.txt の標準
  • データ文書（.json .xml .yaml）には分割表示がなく、プレビュー ⇄ 編集 だけを切り替えます — 下の「データ文書の表示」を参照

拡大・縮小

どこでも同じ操作です: トラックパッドでピンチ、または ⌘ + スクロール。

  • プレビュー: 表示倍率（縮小すると縦により多くの内容が見えます）
  • エディタ: 文字サイズ（10〜24pt）
  • PDF: ページの倍率
  • 画像・図の拡大表示の中でも同じ
  • メニューからは: ⌘ + / ⌘ − / ⌘ 0（プレビューとエディタで別々に記憶）

記法パレット — ⌥ を押したまま（Mac）

編集中に ⌥（option）を押したままにすると、右下にパレットが開きます。キーボードと同じ位置に並んでいて、押している間は対応するキーで書式を入れられます。書式はすべてオン・オフの切り替えです — 同じキーをもう一度押すと解除されます。

キー 機能 キー 機能
1〜6, 0 見出し 1〜6 · 本文 A 見出しの切り替え
S 太字（⌘B） D 斜体（⌘I）
F 取り消し線 G インラインコード
H 箇条書き J 番号付きリスト
K チェックボックス L 引用
Z リンク（⌘K） X 画像
C コードブロック（⌘⇧K） V 表
B 区切り線

⌘, 設定

プレビューの機能

  • フォントをすばやく切り替える：ツールバーの「あぁ」ボタンで、本文と見出しのフォント（明朝・ゴシック）とテーマ（自動・ライト・ダーク）をすぐに切り替えられます。設定 › プレビューと同じ値なので、すべての書類に適用され、次に開いたときもそのままです。
  • 目次: ⌘⇧T または目次アイコン — 左側のパネル。幅はドラッグで調整できます。項目をクリックすると移動します
  • 本文の幅: 全幅 / 広い / 標準 / 狭い（左右矢印のアイコン）
  • 画像・図の拡大: クリックすると大きく表示されます。ドラッグ = 移動、ピンチ・⌘ + スクロール = 拡大、ダブルクリック = 画面に合わせる ⇄ 100%、Esc = 閉じる
  • 文書間のリンク: [文書](./別の文書.md) をクリック → 新しいタブで開きます（文書.md#セクション はその見出しへ移動）。Web のリンクはブラウザで開きます
  • Mermaid の図・数式（KaTeX）・フロントマター に対応

編集の機能

  • 日本語・韓国語・中国語の入力（IME）に完全対応 — 変換中に書式が割り込むことはありません
  • Markdown のシンタックスハイライト、行番号、現在行のハイライト
  • 保存はバイト単位でそのまま — 文字コード・BOM・改行コードは元のまま保たれます
  • 文字化けしているときは、ステータスバーの文字コードをクリックして別の文字コードで読み直せます

ファイルの管理

  • 外部での変更の検知: ほかのアプリが開いているファイルを変更すると、自動で読み直します。編集中だった場合はバナーで確認します
  • 保存していない編集の保管: 保存する前にアプリが終了しても、次に開いたときに編集中の内容が ● 印とともに戻ります。編集したタブを閉じるときは先に確認します
  • セッションの復元: アプリを終了して開き直しても、タブ・表示モード・スクロール位置までそのまま
  • 画像フォルダの許可: 文書の画像が表示されないときは、上部バナーの「フォルダを許可」でアクセスを許可してください（macOS のセキュリティの仕組みによるものです）

PDF

  • ページ一覧: 目次ボタンでページのサムネイル一覧を開きます。Mac · iPad は左側のパネル、iPhone は下から出るシートです
  • PDF ファイルはビューアで開きます（ページの位置を記憶）
  • Markdown → PDF の書き出し: ファイルメニュー → PDFとして書き出す。保存ダイアログで形式（連続 1 ページ / A4 ページ）· 倍率 · 幅広の表・図を幅に合わせるを選べます

設定（⌘,）

  • 一般: テーマ（自動 / ライト / ダーク）· 言語（韓国語 / 英語 / 日本語 / 中国語、再起動後に適用）· 外部での変更の検知 · デフォルトApp · アップデートを自動的に確認（公式サイトからダウンロードした Mac 版のみ）
    • デフォルトApp — すでに Hannun がデフォルトになっている種類には、ボタンの代わりに**「デフォルトに設定済み」**と表示されます
  • プレビュー: 本文の幅 · 本文の書体（セリフ / サンセリフ）· 見出しの書体 · 文字サイズ · データ文書の表示（ソース / ツリー / リスト）
  • エディタ: 等幅フォント · 文字サイズ

対応ファイル

種類 拡張子 プレビュー（表示） 編集
Markdown .md .markdown .mdown .mkd 整形して表示 ✅
テキスト .txt —（エディタで開く） ✅
JSON · XML .json .xml ソース · ツリー · リストのうち設定した表示 ✅ ハイライト付き
YAML .yaml .yml ソース + 折りたたみ ✅ ハイライト付き
PDF .pdf 専用ビューア —
  • どの形式も開き方は同じです — ⌘O、Finder からのドラッグ、場所ボタン（Mac）、ファイルボタン（iPhone・iPad）、文書内のリンク
  • 文書の中の [別の文書](./別の文書.md) のようなリンクも、上の拡張子なら Hannun の新しいタブで開きます

データ文書の表示（JSON · XML · YAML）

データ文書はプレビューで折りたたんだり展開したりしながら読みます。表示のしかたは設定 › プレビュー › データ文書の表示で選びます。文書を開いたまま変えると、その場で表示し直されます。

表示 見た目
ソース（標準） ファイルに書かれたとおりに表示し、括弧の単位で折りたたみます。VS Code などのエディタと同じ見た目です。折りたたんだ行は { … }, のように表示されます
ツリー 引用符や括弧を外し、名前と値だけを表示します。折りたたんだ行の横の小さな数字は、中に入っている数です。同じ形の項目が並んでいると表にまとめ、200 行ずつ表示して「残り N 行を表示」で続きを見られます
リスト キー · 型 · 値を 3 列に分けて表示します。Xcode のプロパティリストと同じ見た目です
  • YAML はソース表示のみで、インデント単位で折りたたみます。ツリー・リスト表示は今後のアップデートで追加する予定です
  • 大きなファイル（ノードが 1,000 を超えるもの）は、2 階層まで展開した状態で開きます
  • 拡大・縮小、検索、PDF の書き出し、テーマ、本文の幅は Markdown と同じように使えます
  • 折りたたんだ行の中の文字は検索にかかりません — 画面に表示されていない文字だからです。先に展開してから検索してください
  • プレビューでは値を直せません。直すときは ⌘/ で編集モードに切り替え、そこで直して ⌘S で保存します

iPad · iPhone

  • ファイルを開く: ファイルボタンを押して、「ファイル」App にある文書を選びます。文書はその場で開き、直した内容は元のファイルに保存されます
  • 共有で受け取った書類: メールやメッセージアプリから共有で受け取ったファイルはコピーなので、読み取り専用で開きます。編集するには、先に「ファイル」App に保存してからそのファイルを開いてください
  • 記法パレット: 編集画面の右下のボタンから開きます
  • 分割表示（iPad）: エディタとプレビューを並べて表示します。中央の境界線をドラッグして幅を調整でき、左右のスクロールは連動します
  • 目次（iPhone）: 右下の、ファイルを開くボタンの上にあります
  • 検索 · 置換: iPad ではメニューバーから使います
  • 拡大 · 縮小: 2 本指で広げたり狭めたりします
