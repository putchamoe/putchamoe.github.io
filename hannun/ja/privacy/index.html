プライバシーポリシー

Hannun は利用者の情報を一切収集しません。インターネットに接続するのは、ウェブサイトから入手した無料の Mac 版がアップデートを確認するときだけで、設定でオフにできます。

施行日: 2026年9月26日

Hannun(한눈)は、利用者のいかなる情報も収集しません。

収集しないもの

  • 個人情報 — 氏名・メールアドレス・電話番号・住所など一切
  • アカウント — 登録もログインもありません
  • 利用状況 — 解析ツール、利用統計、クラッシュレポートツールを組み込んでいません
  • 広告識別子 — 広告を表示せず、追跡も行いません

文書は端末の外に出ません

Hannun は利用者が開いた Markdown・テキスト・データ・PDF ファイルを端末内でのみ読み書きします。文書の内容も、ファイル名も、開いたという事実も開発者に送信されず、開発者が知る手段はありません。

端末に保存されるもの

以下は動作に必要なため端末内のアプリの保存領域にのみ保存されます。外部には送信されず、アプリを削除すると併せて消去されます。

項目 内容
設定 テーマ・フォント・本文幅・言語
セッション 開いているタブ、スクロール位置、表示モード
一時文書 未保存の内容の自動バックアップ
最近の文書 最近開いたファイルの一覧と、再び開くためのアクセス権
フォルダアクセス権 文書フォルダの画像を表示するために許可された範囲

開発者が保有する利用者データはないため、削除を依頼する対象もありません。端末に保存された項目を消去するには、アプリを削除してください。

Hannun は独自の iCloud 同期を行いません。iCloud Drive 上のファイルを開く場合、ダウンロードはOSが処理します。

ネットワーク

文書を開く・読む・編集するためにインターネットは使いません。数式・ダイアグラム・フォントはアプリに内蔵されています。プレビューは外部アクセスを遮断しているため、文書が参照する外部画像も読み込みません。

ウェブからダウンロードした Mac 版は、新しい版があるかを確認するため更新情報ファイル(putchamoe.com/hannun-releases/appcast.xml)に接続します。

  • サーバーに届くのは一般的なウェブリクエストの情報だけです — アプリ名と版番号、macOS の版番号を含むリクエストヘッダー、接続に使われた IP アドレス。文書や端末の情報は送信しません
  • 更新情報ファイルは GitHub Pages に、更新ファイルは GitHub Releases に置かれています。アクセス記録は GitHub のプライバシーステートメントに従って扱われます
  • 設定 › 一般 › アップデートを自動的に確認 をオフにすると、アプリが自ら接続することはありません

App Store 版は更新をOSに任せるため、アプリが自ら開く接続はありません。ネットワーク権限は、プレビューを描画するシステム部品(WebKit)の動作に必要なため有効になっています。

クラッシュレポート

利用者が端末の設定で「App デベロッパと共有」をオンにしている場合、Apple がクラッシュレポートを開発者に提供することがあります。これはOSの機能であり、Hannun が独自に収集するものではありません。

外部リンク

文書内のリンクを押すと、既定のウェブブラウザが開きます。移動先には各サイトの方針が適用され、Hannun は関与しません。

児童

Hannun は児童を対象としておらず、児童を含む誰の情報も収集しません。

変更

方針を変更した場合は、このページに掲載し施行日を更新します。
