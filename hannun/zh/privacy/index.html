隐私政策

Hannun 不收集您的任何信息。只有从官网下载的免费 Mac 版会在检查更新时联网，且可在设置中关闭。

生效日期: 2026年10月1日

Hannun(한눈)不收集用户的任何信息。

我们不收集的内容

  • 个人信息 — 不收集姓名、邮箱、电话号码、地址等任何信息
  • 账号 — 无需注册，也无需登录
  • 使用数据 — 未接入分析工具、使用统计或崩溃报告工具
  • 广告标识符 — 不展示广告，也不进行追踪

文档不会离开您的设备

Hannun 仅在您的设备上读写您打开的 Markdown、文本、数据和 PDF 文件。文档内容、文件名，以及您曾打开过它们这一事实，都不会传输给开发者，开发者也无从得知。

保存在设备上的内容

以下内容因应用运行所需而仅保存在您设备上的应用存储空间中，不会传输到任何地方；删除应用即一并清除。

项目 内容
设置 主题、字体、正文宽度、语言
会话 已打开的标签页、滚动位置、显示模式
临时文档 · 正在编辑的文件 保存前的书写与修改内容的自动备份
最近文档 最近打开的文件列表，以及重新打开它们所需的访问权限
文件夹访问权限 为显示文档目录中的图片而由您授权的范围

由于开发者不持有任何用户数据，因此也不存在需要申请删除的数据。如需清除设备上保存的内容，删除应用即可。

Hannun 不会自行通过 iCloud 同步。打开 iCloud 云盘中的文件时，下载由操作系统处理。

网络

打开、阅读和编辑文档都不需要联网。公式、图表和字体均内置于应用中。文档预览已阻断外部访问，因此文档中引用的外部图片同样不会加载。

从网站下载的 Mac 版会连接更新信息文件(putchamoe.com/hannun-releases/appcast.xml)以检查是否有新版本。

  • 服务器仅会收到普通的网络请求信息 — 包含应用名称与版本号、macOS 版本号的请求头，以及连接所用的 IP 地址。不会发送文档或设备信息
  • 更新信息文件托管于 GitHub Pages，更新文件托管于 GitHub Releases。访问记录按 GitHub 隐私声明处理
  • 关闭 设置 › 通用 › 自动检查更新 后，应用将不会自行联网

App Store 版由操作系统负责更新，应用不会自行发起连接。开启网络权限是因为绘制预览的系统组件(WebKit)运行时需要。

崩溃报告

如果您在设备设置中开启了"与 App 开发者共享"，Apple 可能会将崩溃报告提供给开发者。这是操作系统的功能，Hannun 本身不收集任何信息。

外部链接

点击文档中的链接会打开您的默认浏览器。跳转后的网站适用其各自的隐私政策，Hannun 不参与其中。

儿童

Hannun 并非面向儿童，且不收集包括儿童在内的任何人的信息。

变更

政策如有变更，将在本页面公布并更新生效日期。
