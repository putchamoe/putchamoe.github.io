개인정보처리방침

한눈은 이용자의 어떤 정보도 수집하지 않습니다. 홈페이지에서 받은 Mac 무료 버전만 업데이트 확인을 위해 인터넷에 접속하며, 설정에서 끌 수 있습니다.

시행일: 2026년 9월 26일

한눈은 이용자의 어떤 정보도 수집하지 않습니다.

수집하지 않는 것

  • 개인정보 — 이름·이메일·전화번호·주소 등 일체
  • 계정 — 회원가입·로그인 절차가 없습니다
  • 이용 기록 — 분석 도구, 사용 통계, 크래시 리포트 도구를 넣지 않았습니다
  • 광고 식별자 — 광고를 표시하지 않으며 추적하지 않습니다

문서는 기기를 벗어나지 않습니다

한눈은 이용자가 연 마크다운·텍스트·데이터·PDF 파일을 기기 안에서만 읽고 씁니다. 문서의 내용도, 파일 이름도, 열었다는 사실도 개발자에게 전송되지 않으며 개발자는 이를 알 수 없습니다.

기기에 저장되는 것

아래 항목은 앱 동작에 필요해 이용자 기기의 앱 저장 공간 안에만 저장됩니다. 외부로 전송되지 않으며, 앱을 삭제하면 함께 지워집니다.

항목 내용
설정 테마·글꼴·본문 너비·언어 등
세션 열린 탭 목록, 스크롤 위치, 보기 모드
임시 문서 저장하지 않은 작성 내용의 자동 백업
최근 문서 최근에 연 파일 목록과, 그 파일을 다시 열기 위한 접근 권한
폴더 접근 권한 문서 폴더의 이미지를 표시하기 위해 이용자가 허용한 범위

개발자가 보관하는 이용자 정보가 없으므로 따로 삭제를 요청할 대상도 없습니다. 기기에 저장된 항목을 지우려면 앱을 삭제하면 됩니다.

한눈은 iCloud 동기화를 따로 하지 않습니다. iCloud Drive에 있는 파일을 열면 내려받기는 운영체제가 처리합니다.

네트워크

문서를 열고 읽고 고치는 데 인터넷을 쓰지 않습니다. 수식·다이어그램·글꼴은 앱 안에 들어 있습니다. 문서 미리보기는 외부 접속이 차단되어 있어, 문서에 들어 있는 외부 이미지도 불러오지 않습니다.

홈페이지에서 받은 Mac 무료 버전은 새 버전이 나왔는지 확인하기 위해 업데이트 정보 파일(putchamoe.com/hannun-releases/appcast.xml)에 접속합니다.

  • 이때 서버에 전달되는 것은 일반적인 웹 요청 정보뿐입니다 — 앱 이름과 버전, macOS 버전이 담긴 요청 헤더, 그리고 접속에 쓰인 IP 주소. 문서나 기기 정보는 보내지 않습니다
  • 업데이트 정보 파일은 GitHub Pages에, 업데이트 파일은 GitHub Releases에 있습니다. 접속 기록은 GitHub의 개인정보처리방침에 따라 처리됩니다
  • 설정 › 일반 › 자동으로 업데이트 확인을 끄면 앱이 스스로 접속하지 않습니다

App Store 버전은 업데이트를 운영체제가 처리하므로 앱이 스스로 여는 연결이 없습니다. 네트워크 권한이 켜져 있는 것은 미리보기를 그리는 시스템 구성요소(WebKit)가 동작하는 데 필요하기 때문입니다.

크래시 보고서

이용자가 기기 설정에서 "앱 개발자와 공유"를 켠 경우, Apple이 크래시 보고서를 개발자에게 전달할 수 있습니다. 이는 운영체제의 기능이며 한눈이 따로 수집하는 것이 아닙니다.

외부 링크

문서 안의 링크를 누르면 기본 웹 브라우저가 열립니다. 이동한 사이트에는 각자의 개인정보처리방침이 적용되며 한눈은 관여하지 않습니다.

아동

한눈은 아동을 대상으로 하지 않으며, 아동을 포함한 누구의 정보도 수집하지 않습니다.
