한눈 사용 설명서

파일을 여는 법부터 단축키, 문법 팔레트, 데이터 문서 보기까지. 문제가 생겼다면 지원 페이지를 보세요.

시작하기

  • 파일 열기: 파인더 더블클릭(기본 앱 설정 시), ⌘O, 창에 파일 드래그, 시계(⏱) 메뉴의 최근 문서
  • 새 문서: ⌘N 또는 탭 줄의 + — 저장 위치를 묻지 않는 임시 문서가 바로 열립니다. 내용은 자동 백업되고, 앱을 껐다 켜도 그대로 남습니다. ⌘S 로 저장하면 일반 파일이 됩니다.
  • 기본 앱 설정: 설정 > 일반 > 기본 앱에서 마크다운·텍스트·PDF·데이터 문서를 각각 등록할 수 있습니다.

화면 구성 (Mac)

위치 내용
타이틀 줄 왼쪽에 문서 상태 문구 · 오른쪽에 버튼 세 묶음 — 이동(시계: 탭·최근 문서 / 위치: 파인더에서 보기) · 보기(본문 너비 / 목차 / 보기 전환) · 내보내기·앱(공유 / 설정)
탭 줄 열린 문서들(타입 아이콘 + 이름) · + 새 문서 · 탭이 2개 이상이면 오른쪽에 탭 개수
상태 표시줄 편집 중일 때만 — 줄:칸 · 인코딩(클릭해 재해석) · 줄바꿈 형식

탭이 넘치면 좌우로 스크롤됩니다 (트랙패드 가로 제스처, 마우스 휠 모두).

보기 모드 — ⌘/

프리뷰 → 스플릿 → 편집을 순환합니다.

  • 프리뷰: 렌더된 문서 전면. 마크다운 파일의 기본
  • 스플릿: 좌 편집기 / 우 프리뷰. 분할선은 드래그로 조절되고 탭별로 기억됩니다. 양쪽 스크롤은 자동으로 맞춰집니다
  • 편집: 편집기 전면. .txt 의 기본
  • 데이터 문서(.json .xml .yaml)는 스플릿이 없고 프리뷰 ⇄ 편집만 오갑니다 — 아래 "데이터 문서 보기" 참고

확대·축소

어디서나 같은 방법: 트랙패드 핀치 또는 ⌘+스크롤.

  • 프리뷰: 화면 배율 (축소하면 세로로 더 많은 내용이 보입니다)
  • 편집기: 글자 크기 (11~24pt)
  • PDF: 페이지 배율
  • 이미지·다이어그램 확대 팝업 안에서도 동일
  • 메뉴 방식: ⌘ + / ⌘ − / ⌘ 0 (프리뷰·편집기 각각 기억)

문법 팔레트 — ⌥ 길게 누르기 (Mac)

편집 중 ⌥(옵션)를 누르고 있으면 우하단에 팔레트가 열립니다. 키보드 위치 그대로 배열되어 있고, 누르고 있는 동안 해당 키로 서식을 넣습니다. 모든 서식은 토글 — 같은 키를 다시 누르면 해제됩니다.

키 기능 키 기능
1~6, 0 제목 1~6 · 본문 A 제목 순환
S 굵게 (⌘B) D 기울임 (⌘I)
F 취소선 G 인라인 코드
H 불릿 J 번호 목록
K 체크박스 L 인용
Z 링크 (⌘K) X 이미지

프리뷰 기능

  • 목차: ⌘⇧T 또는 목차 아이콘 — 왼편 패널, 폭 드래그 조절. 항목 클릭으로 이동
  • 본문 너비: 전체 / 넓게 / 보통 / 좁게 (좌우 화살표 아이콘)
  • 이미지·다이어그램 확대: 클릭하면 팝업으로 커집니다. 드래그 = 이동, 핀치·⌘+스크롤 = 확대, 더블클릭 = 맞춤⇄100%, Esc = 닫기
  • 문서 간 링크: [문서](./다른문서.md) 클릭 → 새 탭으로 열림 (문서.md#섹션 은 해당 제목으로 이동). 웹 링크는 브라우저로
  • Mermaid 다이어그램·수식(KaTeX)·frontmatter 카드 지원

편집 기능

  • 한글·일본어·중국어 입력(IME) 완전 지원 — 조합 중 서식이 개입하지 않습니다
  • 마크다운 구문 강조, 줄 번호, 현재 줄 강조
  • 저장은 바이트 보존 — 인코딩·BOM·줄바꿈이 원본 그대로 유지됩니다
  • 인코딩이 깨져 보이면 상태 표시줄의 인코딩을 클릭해 다른 인코딩으로 재해석

파일 관리

  • 외부 변경 감지: 다른 앱이 열린 파일을 바꾸면 자동으로 다시 읽습니다. 편집 중이었다면 배너로 물어봅니다
  • 세션 복원: 앱을 껐다 켜면 탭·보기 모드·스크롤 위치까지 그대로
  • 이미지 폴더 허용: 문서의 이미지가 안 보이면 상단 배너의 "폴더 허용"으로 접근을 허용하세요 (macOS 보안 규칙)

PDF

  • PDF 파일은 뷰어로 열립니다 (페이지 위치 기억)
  • 마크다운 → PDF 내보내기: 파일 메뉴 → PDF로 내보내기. 저장 창에서 형식(연속 한 장 / A4 페이지) · 배율 · 넓은 표·다이어그램 너비 맞춤을 고를 수 있습니다

설정 (⌘,)

  • 일반: 테마(자동/라이트/다크) · 언어(한국어/영어/일본어/중국어, 재시작 적용) · 외부 변경 감지 · 기본 앱 · 자동으로 업데이트 확인(홈페이지에서 받은 Mac 무료 버전만)
    • 기본 앱 — 한눈이 이미 기본 앱인 형식은 버튼 대신 "기본 앱으로 설정됨" 이 보입니다
  • 프리뷰: 본문 너비 · 본문 계열(세리프/산세리프) · 제목 계열 · 글자 크기 · 데이터 문서 보기(원문/트리/목록)
  • 편집기: 고정폭 폰트 · 글자 크기

일반 텍스트 .txt — (편집기로 열림) ✅

  • 여는 길은 어느 형식이든 같습니다 — ⌘O, Finder에서 끌어다 놓기, 위치 버튼(Mac), 파일 버튼(iPhone·iPad), 문서 안의 링크
  • 문서 안에서 [다른 문서](./다른문서.md) 처럼 걸어 둔 링크도 위 확장자면 한눈 안에서 새 탭으로 열립니다

데이터 문서 보기 (JSON · XML · YAML)

데이터 문서는 프리뷰에서 접고 펴며 읽습니다. 보는 방식은 설정 › 프리뷰 › 데이터 문서 보기에서 고릅니다. 문서를 연 채로 바꾸면 그 자리에서 다시 그려집니다.

방식 모양
원문 (기본) 파일에 적힌 그대로 보고, 괄호 단위로 접습니다. VS Code 같은 편집기와 같은 모양입니다. 접힌 줄은 { … }, 로 보입니다
트리 따옴표와 괄호를 빼고 이름과 값만 보여 줍니다. 접힌 줄 옆 작은 숫자는 그 안에 든 개수입니다. 같은 모양의 항목이 줄지어 있으면 표로 정리하고, 200행씩 보여 주며 "나머지 N행 더 보기"로 이어 봅니다
목록 키 · 형식 · 값을 세 칸으로 나눠 보여 줍니다. Xcode 속성 목록과 같은 모양입니다
  • YAML 은 원문으로만 보이며 들여쓰기 단위로 접힙니다. 트리·목록 보기는 업데이트로 추가될 예정입니다
  • 큰 파일(노드 1,000개 초과)은 2단계까지만 펼친 채로 시작합니다
  • 확대·축소, 찾기, PDF 내보내기, 테마, 본문 너비가 마크다운과 똑같이 듣습니다
  • 접힌 줄 안의 글자는 찾기에 걸리지 않습니다 — 화면에 없는 글자이기 때문입니다. 먼저 펼친 뒤 찾으세요
  • 프리뷰에서는 값을 고칠 수 없습니다. 고치려면 ⌘/ 로 편집 모드로 넘어가세요 — 거기서 고치고 ⌘S 로 저장합니다

iPad · iPhone

  • 파일 열기: 파일 버튼을 눌러 파일 앱에 있는 문서를 고릅니다. 문서는 제자리에서 열리고, 고친 내용은 원본에 저장됩니다
  • 문법 팔레트: 편집 화면 오른쪽 아래의 버튼으로 엽니다
  • 찾기 · 바꾸기: 아이패드는 메뉴 막대에서 씁니다
  • 확대 · 축소: 두 손가락으로 벌리고 오므립니다
